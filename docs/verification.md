# 埋め込み型ウィジェットへの修正：検証記録

2026-10-25。仕様の照合と仮仕様は [spec-reconciliation.md](spec-reconciliation.md) を参照。

## ローカルで通過した検証

- TypeScriptと、公開体験版・Owner版それぞれのビルド。
- 単体テスト20件：Owner認可、署名付きJWT、CSRF、入力・画像検証、公開同意、投げ銭の初期OFF、CSV数式対策、日本語フォント埋め込み、長文分割、印刷寸法・補正値。
- 埋め込みブラウザテスト6件：128×52pxのボタン単体、表示だけでは加算なし、クリックによる拍手保存、お礼画像、感想なしで閉じても拍手が残ること、本文の位置が不変、PC・390px幅のスマートフォン画面。
- 別オリジンの実HTTPページからのscript/iframe埋め込み、ホスト側の強いiframe/button CSSの隔離、偽造postMessageの拒否。
- 保存失敗時はお礼を開かず、成功を表示しないこと。お気に入りの端末内保存、任意メッセージ、返信URL、別ブラウザでの閲覧拒否。
- 機能OFFの反映、公開許可の初期OFF、未接続の投げ銭を表示しないこと。
- Owner版のD1/R2エミュレーターによる連携テスト10件：認証境界・重複抑止・非公開返信・URL無効化/再発行・ブロック/削除・画像安全対策・設定フラグ・CSV/JSON・画像込み完全復元・日本語PDF・PC/スマホ・頻度制限。
- `wrangler deploy --dry-run`：既存のデプロイコマンドでビルドし、静的ファイルとASSETSバインディングを検出。
- ローカルD1に0002マイグレーションを適用。本番D1/R2は作成・更新していない。
