# 統計印刷の手帳サイズ

管理画面ダッシュボードの「統計を印刷」で選べるサイズ。幅と高さは画面で変更でき、ブラウザに保存される。

| 手帳 | 既定サイズ（幅×高さ） | 根拠 |
| --- | --- | --- |
| ジブン手帳 A5スリム ウィークリー1日分 | 24×168mm | 推定。本体は210×130mm（コクヨ公式）。1日の列幅は公式非公開 |
| ほぼ日手帳 オリジナル デイリー | 88×122mm | 推定。本体A6（105×148mm）、方眼3.7mm（ほぼ日公式）。書ける範囲は公式非公開 |
| ほぼ日手帳 カズン デイリー | 130×184mm | 推定。本体A5（148×210mm）。書ける範囲は公式非公開 |
| ほぼ日手帳 カズン ウィークリー1日分 | 120×24mm | 推定。公式非公開 |
| システムダイアリー リフィル | 82×140mm | 8穴の独自サイズ。左7mmを穴用に空ける |
| システム手帳 バイブル | 95×170mm | 一般的なリフィル寸法。左7mmを穴用に空ける |
| システム手帳 バイブルナロー | 80×170mm | 同上 |
| システム手帳 A5 | 148×210mm | 同上 |
| システム手帳 ミニ6穴 | 64×127mm | 同上 |
| システム手帳 M5 | 62×105mm | 同上 |

「A4に並べて裁断線を付ける」をオンにすると、A4に入るだけ並べて四隅に裁断線を付ける。オフにすると手帳サイズのPDFになる。
